# ADR 0002: Deterministic search and state ownership

Status: accepted; the original single-thread search design was extended by Phase 2 P2-4 SMP support.

Iterative deepening always completes depth one before honoring stop, so an immediate stop produces a searched legal move. Higher iterations check cancellation, node limits and the monotonic clock at every node. The last complete iteration supplies the result; incomplete iterations never replace it. Explicit movetime uses the requested milliseconds. Clock allocation reserves Move Overhead, divides usable time by moves-to-go (default 30), adds 75% of increment and caps spending at one quarter of usable time. Ponder time allocation starts at ponderhit. Depth, nodes and clocks combine by whichever ends first.

Negamax uses alpha-beta/PVS, aspiration windows, TT ordering, MVV-LVA/SEE, two killers per ply, and bounded history scores. Null move requires at least two non-pawn/non-king pieces, no check, sufficient depth and a static beta advantage. Reduction is 2 + depth/6. LMR and frontier futility apply only at non-principal-variation nodes, on quiet non-checking moves, never while in check. Mate-three regression fixtures caught and prohibited reducing/pruning PV nodes. Quiescence searches captures and quiet promotions or all legal check evasions; it detects stalemate before stand-pat.

The TT is fixed-sized and four-way associative, with full keys, generation aging and depth-preferred replacement. Bucket reads/writes are protected by 1,024 stripe locks for SMP; clear, resize and generation changes occur only while the coordinator has no active workers. Shallower same-generation results preserve deeper entries. Mate scores are normalized on store/probe for ply-independent distance. The search mixes the halfmove clock into its TT key without changing Core repetition identity; fifty-move-dependent scores cannot leak between clocks. Rule draws precede TT use; repeated positions do not accept TT cutoffs. Only non-PV windows accept cutoffs, preserving searched principal variations. Mate/no-move detection precedes rule draws.

Each Engine search runs on a dedicated LongRunning coordinator. The coordinator owns the root position and, for `Threads` greater than one, creates independent `Searcher`, history-preserving `Position`, and evaluator state per worker. It cancels peers on worker failure and joins every worker before the task completes. Facade state mutations are rejected until the search task finishes. Adapters must cancel and await before changing position/options. Arrays for PV, killers and history are allocated once per Searcher; recursive search uses stack spans. Observer snapshots allocate only at iteration boundaries, outside the node hot path.

Depth is bounded by the fixed search stack (94 plies); `Threads` defaults to one and accepts 1–128. The one-thread path retains the deterministic benchmark signature; concurrent SMP search may produce different nodes and moves between runs. UCI pondering starts time management at ponderhit; MultiPV searches and reports distinct root lines. Optional WDL output uses a Stockfish empirical model and is not calibrated to Zwischenzug. Heuristics reset each search; NewGame clears TT. Deterministic benchmark positions start from cleared state.
